### 4. 판단 훈련 정답 기준: 인기 vs 결과
판단 장면의 정답을 무엇으로 정할지 따로 떼어 둔 고수 판으로 확인했어요. 숫자는 "정답으로 고른 선택을 실제로 한 판의 2분 뒤 성과 좋음 비율" vs "다른 선택을 한 판"이에요.

| 정답 기준 | 정답을 따른 판 | 따르지 않은 판 | 차이 |
|---|---|---|---|
| 고수가 많이 고른 것 (20% 이상) | 52.7% | 44.4% | +8.3%p |
| 인기 + 결과 섞기 | 43.5% | 37.7% | +5.8%p |
| 2분 뒤 결과가 가장 좋았던 것 | 27.1% | 24.8% | +2.3%p |

결과만으로 고른 정답은 거의 가르지 못했어요(비슷한 장면 수가 적어 결과가 잡음에 묻힘). 그래서 정답은 **고수가 많이 고른 선택**으로 두고, 결과 1위는 '참고' 배지로만 보여 줘요.

### 5. 같은 플레이어 안에서 비교 (지렛대인가, 습관 표시인가)
티어를 가르는 지표라도 "그걸 고치면 이기나"는 다른 질문이에요. 고수·플래티넘 194명의 3,644판에서, 한 사람의 판을 그 사람 평소(중앙값)보다 좋았던 판과 나빴던 판으로 나눠 승률을 비교했어요 (`scripts/within_player.py`).

| 지표 | 평소보다 좋았던 판의 승률 차이 | 판단 |
|---|---|---|
| 죽어 있던 시간 비율 | +45%p | 지렛대 |
| 15분 전체 CS | +20.5%p | 지렛대 |
| 분당 핑 | +15.4%p | 지렛대 |
| 6레벨 시각 | +13.7%p | 지렛대 |
| 10분 정글 CS | +13%p | 지렛대 |
| 킬 관여율 | −3%p | 습관 표시 |
| '적 시야' 핑 | −3.4%p | 습관 표시 |
| 미아 핑 | −4.1%p | 습관 표시 |

- 이긴 판이라 지표가 좋아졌을 수 있어서(역인과) 원인이라고 단정하진 않아요.
- 습관 표시 지표(+5%p 미만)는 1순위 계산에서 0.35배로 낮췄고, 화면에 "습관을 보여 주는 표시"라고 적어요.
- 미아 핑은 티어는 잘 가르지만 같은 사람 안에서는 승률과 이어지지 않았어요. 핑 개수보다 맵을 보는 습관 자체가 중요하다는 뜻으로 읽어요.
